# MirthSpool v0.1.9

This patch release aligns the isolated browser fixture network with the exact
host allowlist required by the hardened outbound-fetch policy.

## Install and verify

Follow [the installation guide](../INSTALL.md) and use only the immutable
`ghcr.io/...@sha256:` references attached to this release. The release workflow
builds and scans both images, runs browser tests, publishes per-image SPDX
SBOMs, and creates GitHub build-provenance attestations tied to this tag.

## Migration and rollback

Run the documented migration deployment command before starting v0.1.9. The
forward-only `20260728233000_ifunny_source` migration remains the newest schema
change. Rollback remains restore-from-verified-backup.

## Security notes

- Private source and media fixtures are allowlisted by their exact isolated
  Compose DNS names; production allowlists remain empty by default.
- Secret, CodeQL, dependency, container, integration, and browser gates remain
  required before publication.

## Known limitations

- Release images target `linux/amd64`.
- TLS and reverse-proxy lifecycle remain operator-owned.
- PostgreSQL rollback is restore-based rather than down migrations.
- Private destinations remain denied unless explicitly reviewed and allowlisted.
